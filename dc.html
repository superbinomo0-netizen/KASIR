Install Pintasan DokumenKu di PC

Cara 1: Install Aplikasi Jendela (Chrome / Edge)
  1. Klik ikon Titik Tiga (⋮) di pojok kanan atas browser Chrome/Edge.
  2. Pilih menu Cast, save, and share (atau Simpan dan bagikan) → klik Install page as app... / Create shortcut...
  3. Centang Open as window (Buka sebagai jendela), lalu klik Create / Install.
  4. Pintasan DokumenKu otomatis muncul di Desktop PC dan Start Menu!
Cara 2: Unduh File Aplikasi HTML Offline

Simpan file DokumenKu.html langsung ke Desktop PC Anda agar bisa dibuka kapan saja tanpa internet dengan klik ganda.
